# 매물레이더

마포·성동·영등포 20평대 아파트를 매일 아침 살펴보고, 지금 사기 좋은 곳 10개를 골라 주는 개인용 사이트예요.

- **데이터**: 국토교통부 실거래가(매매·전월세), (선택) 한국부동산원 R-ONE 주간 지수
- **매일 자동 실행**: GitHub Actions가 매일 오전 5시 50분에 데이터를 모으고 사이트를 새로 만들어요
- **사이트 주소**: GitHub Pages (`https://<내 아이디>.github.io/<저장소 이름>/`)

> 인증키를 넣기 전에는 **테스트 데이터**(가짜 단지·가짜 숫자)로 화면이 떠요. 화면 위에 노란 표시가 붙어 있어요.

## 처음 한 번만 하는 설정

### 1. 인증키 신청 (무료)

**공공데이터포털** (data.go.kr) 에 로그인하고 아래 두 개를 각각 '활용신청' 해요.

1. `국토교통부_아파트 매매 실거래가 자료`
2. `국토교통부_아파트 전월세 실거래가 자료` (선택 · 없으면 전세 정보만 빠져요)

(선택, 추천) 세대수·동 수·난방·주차를 정확히 받으려면 아래 두 개도 신청해요. 안 하면 세대수를 거래량으로 추정해요.

3. `국토교통부_공동주택 단지 목록제공 서비스`
4. `국토교통부_공동주택 기본 정보제공 서비스`

승인되면 마이페이지 > 개발계정에서 **일반 인증키**를 복사해요. (Encoding·Decoding 어느 쪽이든 괜찮아요.)
승인 직후 1~2시간은 키가 아직 안 먹을 수 있어요.

(선택) **한국부동산원 R-ONE** (reb.or.kr/r-one) > 오픈API 에서 인증키를 받으면 지역 리포트에 주간 가격지수가 추가돼요.

### 2. GitHub 저장소 만들기

1. github.com 에서 새 저장소(New repository)를 만들어요. 무료 계정은 **Public** 이어야 사이트를 띄울 수 있어요.
2. 이 폴더의 파일을 모두 올려요.

### 3. 인증키 넣기

저장소 > **Settings > Secrets and variables > Actions > New repository secret**

| 이름 | 값 |
|---|---|
| `DATA_GO_KR_KEY` | 공공데이터포털 인증키 |
| `RONE_KEY` | (선택) R-ONE 인증키 |

인증키는 이곳에만 넣어요. 파일에 적지 마세요.

### 4. 사이트 켜기

저장소 > **Settings > Pages > Build and deployment > Source** 를 **GitHub Actions** 로 바꿔요.

### 5. 첫 실행

저장소 > **Actions > 매일 아침 데이터 업데이트 > Run workflow**.
처음엔 2019년부터 전부 받아서 5~10분쯤 걸려요. 끝나면 Pages 주소로 들어가 보세요.

## 조건 바꾸기

`config.json` 만 고치면 돼요. 다음 날 아침 추천부터 바뀌어요. 바로 보고 싶으면 Actions에서 Run workflow.

- `regions`: 지역 (법정동 코드 앞 5자리, 예: 마포구 11440)과 구별 기본 출퇴근 시간
- `commute_by_dong`, `school_by_dong`: 동별 출퇴근 시간(분), 학군 점수(1~5)
- `filters`: 면적, 예산(만 원), 최소 세대수(`min_households`, 기본 300), 최소 거래 수, 계산에서 빼는 저층
- `weights`: 점수 비중 (합 100)

돈 계산기 규칙(대출 한도, 세율, 중개 수수료)은 `site/data/rules.json` 에 있어요. 정부 정책이 바뀌면 여기 숫자를 고쳐요.

## 계산 방법 (짧게)

- **전고점**: 같은 단지·같은 전용면적에서 가장 비싸게 거래된 값. 앞뒤 6개월 거래보다 20% 넘게 튀는 거래는 이상치로 보고 빼요.
- **최근 거래가**: 최근 6개월 거래의 중간값 (없으면 1년 안 마지막 거래)
- **계산에서 빼는 거래**: 3층 이하, 직거래, 취소된 거래
- **동네 신호 4가지**: 거래량 증가 · 가격 하락 멈춤 · 전세 상승 · 동네 고점보다 5% 이상 낮음 → 3개 이상이면 '회복 신호'
- **추천 점수**: 전고점 대비 하락, 오를 가능성(동네 신호·전세가율), 출퇴근, 학군, 연식을 비중대로 더해요. 같은 단지는 한 평형만 올려요.

## 내 컴퓨터에서 미리 보기

```bash
python collector/make_sample.py        # 테스트 데이터 만들기
python collector/build.py --sample     # 분석
python -m http.server -d site 8000     # http://localhost:8000
```

실데이터로 보려면 `DATA_GO_KR_KEY=인증키 python collector/fetch_molit.py` 후 `python collector/build.py`.
